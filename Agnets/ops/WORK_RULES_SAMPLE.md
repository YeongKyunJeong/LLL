# Work Rules Sample

필요한 섹션만 참고합니다.
예외가 필요하면 사용자에게 먼저 확인합니다.

## 공통

- 요청 없는 대규모 리팩터링 금지
- 원본 데이터 직접 덮어쓰기 금지
- 자동 생성 파일 직접 수정 금지
- 외부 라이브러리 코드 직접 수정 금지
- 빌드 산출물 직접 수정 금지
- 미검증 완료 보고 금지

## Unity

- `Library/`, `Temp/`, `Obj/`, `Build/`, `Builds/`, `Logs/` 수정 금지
- `Packages/` 외부 패키지 코드 수정 금지
- `.meta` 파일 임의 삭제 금지
- 씬, 프리팹, 에셋 변경 전 영향 범위 확인

## Web

- `node_modules/`, `dist/`, `build/`, `.next/`, `.nuxt/`, `coverage/` 수정 금지
- 잠금 파일은 의존성 변경 시에만 수정
- 기존 디자인 시스템 우선 사용

## Backend

- 운영 설정, 시크릿, 마이그레이션 임의 수정 금지
- 데이터 삭제나 스키마 변경은 사용자 확인 전 금지
- 외부 API 계약 추측 변경 금지
- 로그에 민감 정보 추가 금지

## Data

- 원본 데이터 직접 덮어쓰기 금지
- 변환 결과와 원본을 같은 파일에 저장 금지
- 처리 기준 기록 없이 샘플링, 필터링, 결측 처리 금지
- 수치 결과 검산 없이 확정 보고 금지

## Docs

- 출처 없는 정책 변경 금지
- 오래된 정보를 최신 정보처럼 작성 금지
- 예시와 실제 규칙 혼합 금지
- 긴 원문 반복 복사 금지
