## 1. 개요

보석판(JewelBoard)에 배치되는 보석(Jewel) 타일의 시각 디자인 방향을 정의합니다.
보석은 캐릭터 스킬 발동의 핵심 입력 수단이며, 플레이어가 드래그로 Pop하는 UI 요소입니다.

---

## 2. 보석 색상 체계

보석의 색은 캐릭터의 **상성 클래스(Affinity Class)** 에 따라 5종으로 구분하며, 각 클래스마다 구분이 용이하도록 기본색과 변형색 총 10가지의 구체적인 RGB 색상 값을 정의하여 사용합니다.

## 3. 보석 형태 체계

보석의 형태를 상성 클래스별로 다르게 설정하는 방향을 검토 중입니다.
최종 형태는 샘플 시안을 보고 결정합니다.

| 클래스 | 색상 | 형태 |
|--------|------|------|
| A | 적색 | 8각형 |
| B | 녹색 | 4각형 (정사각형) |
| C | 파란색 | 마름모 (볼록 호형) |
| D | 보라색 | 원형 |
| E | 노란색 | 5각형 (오각형) |

---

## 4. 형태별 설계 원칙

### 공통

- **내부 공간 우선**: 보석 내부에 스킬 아이콘이 들어가야 하므로, 정다각형보다 내부 아이콘 공간이 넓어 보이는 형태를 우선합니다.
- 내부 면 크기 목표: 보석 전체 크기 대비 약 55%
- **보석판 배치 크기 기준**:
  - **마름모(C), 원형(D), 오각형(E)**: 보석 칸에 꽉 차도록 가능한 한 크게 배치합니다.
  - **사각형(B)**: 다른 보석들과의 시각적 크기 균형을 맞추기 위해 약간 작게 조정하여, 보석 칸 외곽에 미세한 여백(틈)이 존재하도록 합니다.

### 8각형 (A, 적색)

- 정팔각형(정다각형)이 아닌, **정사각형에서 모서리만 제거한 형태**
- 상하좌우 변의 길이 ≈ 전체 너비의 70%
- 대각선 변의 길이 ≈ 전체 너비의 20%
- 내부 아이콘 공간이 정사각형에 가깝게 확보됨

### 4각형 (B, 녹색)

- 모서리를 살짝 라운드 처리한 정사각형

### 마름모 — 볼록 호형 (C, 파란색)

- 직선 변 마름모가 아닌, **각 변을 바깥으로 볼록한 곡선 호 4개로 구성한 뚱뚱한 마름모**
- 꼭짓점(상·하·좌·우)은 뾰족하게 유지하되, 변 사이는 바깥으로 팽창한 볼록 곡선
- 정사각형 칸 안에서 내부 아이콘 공간을 최대한 확보하는 것이 목적

### 5각형 (E, 노란색)

- 하단이 평면, 상단에 꼭짓점이 있는 정오각형

### 원형 (D, 보라색)

- 완전한 원

## 5. 비주얼 스타일

- **밝기**: 밝고 선명한 캔디/유리 보석 스타일 (어두운 스톤 느낌 지양)
- **광택**: 내부 면 좌상단에 흰색 하이라이트 광택점 필수
- **베벨**: 테두리에 3D 베벨 효과 (상단 밝은 면 / 하단 어두운 면)

| 요소 | 기준 |
|------|------|
| 베벨 상단 | 주 색상보다 40~50% 밝게 |
| 베벨 하단 | 주 색상보다 40~50% 어둡게 |
| 내부 면 | 주 색상 기준 매우 어두운 버전 + 광택 그라디언트 |
| 광택점 | 순백색, 타원형, 내부 면 좌상단 |

## 6. 인터랙션 및 연출

### 6.1. 선택 및 호버 피드백 (Selection & Hover)
- **정의**: 플레이어가 보석에 마우스 커서를 올리거나(Hover), Pop을 위해 연결 중인 보석 그룹에 포함되었을 때의 시각적 반응.
- **비주얼 연출**:
  - 보석의 테두리가 빛나는 효과(Glow/Outline) 적용.
  - 보석 본연의 색상이 한 단계 더 밝아짐.
  - **외곽 테두리 굵은 선 표시**: 선택된 상태인 경우, 해당 보석의 기본색보다 더 진한 색으로 보석의 외곽 테두리에 굵은 선(Border/Stroke)을 표시하여, 보석 뒤에 깔리는 후광(Glow) 효과와 보석 형태가 뚜렷하게 구분되도록 합니다.
  - **후면 발광 처리**: 빛나는 효과는 다른 보석을 가리지 않도록 보석 이미지의 **뒤쪽(후면)** 에 보이도록 구현합니다. (현재 리소스 디자인 단계에서는 미반영, 개발 시 적용 예정)

### 6.2. 제거 연출 (Pop Effect)
- **연출**: 보석이 Pop되어 제거될 때, 해당 위치에서 파티클 이펙트(Particle Effect) 등으로 보석 부스러기가 튀어나오는 연출을 적용합니다. (디자인 시트 리소스 추가 불필요)

### 6.3. 생성 및 이동 연출 (Spawn & Movement)
- **연출**: 기존의 이동 애니메이션 대신, 보석 제거 후 새로 생성되는 보석 칸 자체의 생성/등장 효과로 이를 대체합니다. (이동 예정 보석에 대한 개별 디자인 필요 없음)
